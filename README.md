# Financial Dashboard Analysis

## Overview
Developed an interactive financial dashboard in Microsoft Excel to analyze revenue, expenses, profit trends, and overall financial performance using dynamic visualizations and KPI reporting.

---

## Tools Used
- Microsoft Excel
- Power Pivot
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers

---

## Features
- Interactive financial dashboard
- KPI tracking and reporting
- Revenue and expense analysis
- Profit trend visualization
- Dynamic filtering using slicers

---

## Skills Demonstrated
- Financial Data Analysis
- Data Cleaning
- Data Visualization
- Dashboard Development
- Business Reporting
